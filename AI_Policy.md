# Foxdroid Labs: AI Policy

Foxdroid Labs maintains a strict policy against AI-generated contributions
across all its repositories. This is intentional, and non-negotiable.

No agents. No bots. No automated PRs. No MCP modifications.
If you didn't write it yourself, don't open a pull request, it will be rejected.

Every line of code in this project is written, reviewed, and understood by a human.
This codebase is human-made and will stay that way.
